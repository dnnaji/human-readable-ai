# Publication boundary

This repository contains portable guidance, aggregate research findings, public source links, and synthetic teaching examples.

Raw conversations, private thread identifiers, local source paths, credentials, device details, third-party personal information, and unrelated personal activity remain outside the repository. The reusable instruction block contains writing guidance only.

The interactive example runs locally without external dependencies, analytics, storage, or service calls. Following a source link opens the named third-party site.

Publication review covers file contents, links, assets, and Git commit metadata. Secret scanning and structural checks support manual review. They cannot guarantee the absence of every disclosure risk.

Third-party material is linked at its source. Repository licenses apply only to the identified original project material. See [SOURCES.md](SOURCES.md).
